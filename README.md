### `OPERATING RULE`

```text
observe the real system
        ↓
model the boundary
        ↓
remove unnecessary layers
        ↓
build the smallest useful path
        ↓
instrument failure
        ↓
ship
        ↓
learn from production
```

I care about the layer between **“it works”** and **“it survives production.”**
